### 2. Cross-Linguistic Patterns (L1 Analysis)

#### Top Performing L1 Groups by Marker Usage:

- **Transitions**: Korean (15.75/1000), Hungarian (16.16/1000), Chinese-Cantonese (16.45/1000)

- **Self Mentions**: Japanese (7.39/1000), Swedish (7.18/1000), German (7.22/1000)

#### Notable L1-Specific Patterns:

**Turkish Learners** (Primary focus):
- Moderate transition usage (13.15/1000) - middle range
- Lower hedge usage (7.62/1000) compared to European L1s
- Moderate self-mention usage (4.70/1000)
- **Pattern**: Turkish learners show more conservative metadiscourse usage

**Chinese Learners** (Major group):
- High transition usage (15.38/1000) - among the highest
- Strong hedge usage (9.83/1000)
- High self-mention usage (6.71/1000)
- **Pattern**: Chinese learners are heavy users of interactive markers

**European L1s** (Germanic/Romance):
- Consistent high hedge usage (10-11/1000)
- Strong booster usage (7-9/1000)
- Moderate self-mention patterns
- **Pattern**: European learners show more interactional sophistication

### 3. Rhetorical Implications

#### Interactive vs. Interactional Balance:
- **Interactive Total**: ~131,848 instances (text organization focus)
- **Interactional Total**: ~162,425 instances (reader engagement focus)
- **Ratio**: 1.23:1 (slightly more interactional than interactive)

#### Cultural Writing Patterns:
1. **East Asian Pattern** (Chinese, Korean, Japanese):
   - High transition usage (text organization priority)
   - Moderate hedge usage (face-saving strategies)
   - High self-mention usage (author visibility)

2. **European Pattern** (Germanic, Romance):
   - Balanced marker usage across categories
   - High hedge usage (academic caution)
   - Strong booster usage (confidence assertion)

3. **Balkan Pattern** (Bulgarian, Serbian, Macedonian):
   - Moderate overall usage
   - Consistent patterns across marker types
   - Balanced interactive/interactional distribution
